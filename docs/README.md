## Правила документации

- Каждый `.md` несёт `> Last reviewed: YYYY-MM-DD` строкой под заголовком; дату бампим при
  содержательной правке и при мерже. Наличие штампа проверяет `tests/repoGuards.test.ts`.
- Один факт — одно место. Нужен в двух документах — во втором ссылка.
- Документация — по-русски (`AGENT_RULES.md` §0).
