# Как делать страницы

> Last reviewed: 2026-09-24

Правила интерфейса. Сжаты из эталона `client-bank-alfa-by` (`docs/PAGE_GUIDE.md`) под это
приложение: у нас нет лендинга с брендовой темой — все рабочие страницы живут во фрейме портала.

## Компоненты — только b24ui

- Интерфейс строится из `@bitrix24/b24ui-nuxt`: `B24Card`, `B24Button`, `B24FormField`,
  `B24Input`, `B24InputNumber`, `B24Select`, `B24RadioGroup`, `B24Textarea`, `B24Tabs`,
  `B24Alert`, `B24Badge`, `B24Skeleton`. Имена и пропы — из документации
  (`https://bitrix24.github.io/b24ui/llms.txt` → страница компонента), не по памяти.
- Цвета — токены b24ui (`air-primary`, `air-secondary`, `air-primary-alert`, `air-primary-warning`,
  `air-primary-success`…) и CSS-переменные `--ui-color-*`, а не свои hex.
- Оболочка — `app/layouts/default.vue`: `B24App` с локалью `ru` (тосты, модалки, подписи
  компонентов). `overflow-x-clip`, а не `hidden`: `hidden` ломает `sticky`.
- Тема — светлая/тёмная по ОС (`app/app.config.ts`: `colorMode`, `colorModeInitialValue: 'auto'`
  — без этих ключей на верхнем уровне `useColorMode()` не работает).
- Таблицы с полями ввода внутри (ставки) и предпросмотр — обычный `<table>` на токенах: слоты
  ячеек `B24Table` в документации не описаны, а рендер через `h()` для таблицы с инпутами
  громоздок.

## Страница во фрейме

- Оборачивается в `<InPortalGate>`: вне портала — объяснение, а не пустой экран. Это забота об
  интерфейсе, не защита — права проверяют портал и сервер.
- Заголовок окна — `$b24.parent.setTitle(...)` после `useB24().init()`.
- Данные с сервера и портала выводятся только через `{{ }}`, никакого `v-html`: названия задач и
  ответы BitrixGPT — внешний текст.
- Разрушительное действие (замена всех товаров счёта, замер места) — с подтверждением.
- У интерактивных элементов — `data-testid` (для будущих визуальных тестов) и доступное имя
  (`label` или `aria-label`).

## Где что лежит

| Что | Где |
|---|---|
| Чистая логика без реактивности | `shared/domain/` (нужна и серверу) или `app/utils/` |
| Реактивность, вызовы портала и сервера | `app/composables/` |
| Константы интеграции (права, встройки) | `app/config/` |
| Компоненты | `app/components/`, по экранам: `settings/`, `invoice/` |

Комментарии и JSDoc — по-русски, пользовательские строки — по-русски, идентификаторы —
по-английски (`docs/AGENT_RULES.md` §0).

## Проверка перед PR

`pnpm check` (линт + типы + тесты) и `pnpm build`. Визуальные регресс-тесты, как в эталоне
(Playwright, скриншоты светлой и тёмной темы), здесь пока не подключены — follow-up.
