# План работ — шпион протокола BitrixGPT

> Last reviewed: 2026-11-01

`shef.aiconnect` (`bx-shef/aiconnect`) — **шпион протокола**: регистрирует в облачном
Битрикс24 сторонний AI-движок (`ai.engine.register`, коды `sh_aiconnect_spy_<category>`) и
записывает, что BitrixGPT присылает на `completions_url`. Это разведка
(bx-shef/aiconnect#19) и первоисточник для bx-shef/toolsai-mcp#155. Модели за шпионом нет:
он отвечает шаблоном, ошибкой или тестовым текстом.

Подключение собственной модели клиента к BitrixGPT — **отдельное облачное приложение**
(решение владельца 2026-11-01, bx-shef/aiconnect#19). Из этого репозитория оно берёт каркас
и замеры `docs/PROTOCOL.md`.

Каждый шаг — свой PR; в `main` напрямую ничего не идёт (`docs/AGENT_RULES.md` §2).

## Сделано

- **Каркас:** установка, токены, проверка фрейма, выкат (bx-shef/aiconnect#5, #6). Сервер
  `aiconnect.bx-shef.by` поднят 2026-11-01.
- **Шпион:** подписанный `completions_url`, запись запросов, ответ 202 и callback только на
  хост портала, страница `/spy` (#11).
- **Первый прогон** на `b24-k82h1m.bitrix24.by` (#20, `docs/PROTOCOL.md`): агент в чате
  отправляет запросы стороннему движку, если в списке «модель AI для общения в чате» выбран
  наш движок.
- **Полный журнал** (`B24_SPY_FULL=1`): тела целиком, метки сценариев, выгрузка JSON (#22).

## Дальше

1. **Сценарии `.by` с метками**, включая звонки. Тестовый звонок — `telephony.externalCall.*`
   по лиду или сделке с озвученным диалогом. В `.by` автозапуска расшифровки нет: по справке
   Битрикс24 автоматический запуск работает только в зоне `ru` по подписке «BitrixGPT +
   Маркетплейс», вне её — только ручной запуск. Звонок распознаётся ручным запуском в карточке.
2. **Сценарии `.ru`** по `docs/SPY_CHECK.md` — сравнение с `.by`.
3. **Выжимка для bx-shef/toolsai-mcp#155:** что BitrixGPT присылает в каждом сценарии, своими
   словами.
4. **Сверка со стендом** (bx-shef/toolsai-stand): где ядро собирает `prompt`, `payload_role`,
   `zero_prompt` (`ai/lib/Payload`, `Engine/ThirdParty.php`). На коробке тексты промптов
   закрыты метками, в облаке приходят раскрытыми.
5. **Категории `call`, `vision`, `classify`:** в списках выбора модели портала их нет; где ядро
   их зовёт — поиск по коду модулей на стенде.

Права приложения: `ai_admin`, `user_brief`; для тестовых звонков шпиона владелец добавил
`telephony` и `crm` (2026-11-01).
