того же сотрудника (`server/utils/b24Client.ts → makeFrameCall`).

## Права приложения

`ai_admin`, `user_brief` — решение владельца (`docs/PLAN.md`, этап 0), сверено с MCP 2026-09-28:

- `ai_admin` — у `ai.engine.register`, `ai.engine.unregister`, `ai.engine.list` на странице
  метода «Scope: ai_admin»; метод только для администратора и только в облаке.
- `user_brief` — «Пользователи (минимальный)», версия права `user` (статья «Доступные скоупы
  Битрикс24»); с ним доступен, например, `user.current` («Scope: user, user_brief, user_basic»).
  Код этапа 0 методов `user.*` не зовёт.
- `profile`, `scope`, `app.info` — «Scope: базовый» в документации. У `event.bind` / `event.get` /
  `event.unbind` страница MCP скоуп не называет; шаблон звал их без отдельного права — подтвердит
  установка на тестовый портал.

Встройки (`placement`), CRM, задачи и каталог шаблона приложению не нужны: их права сняты.

## Не REST, но рядом

- `$b24.installFinish()`, `$b24.parent.setTitle()` — методы фрейма b24jssdk (документация:
  `https://bitrix24.github.io/b24jssdk/llms.txt`).
- `https://<сервер авторизации>/oauth/token/` — продление токена: при установке — для сверки
  `member_id` и домена (`server/utils/verifyInstallMember.ts`). Сервер — из
  `auth[server_endpoint]` события установки (документация события: «Адрес сервера авторизации
  для обновления токена»), только из белого списка `oauth.bitrix24.tech` / `oauth.bitrix.info`
  (`b24Host.ts → resolveOAuthHost`), и хранится в записи о портале. Без поля —
  `oauth.bitrix24.tech`. 📄
- В ответе продления `client_endpoint` — REST-адрес **портала**, а `domain` — хост **сервера
  авторизации**. Домен установки сверяем по `client_endpoint`.
- `keepAuthFresh` из документации b24jssdk в установленной 2.2.0 нет — токен фрейма перед
  запросом к нашему серверу обновляем сами (`app/utils/frameToken.ts`, `docs/ARCHITECTURE.md`).
- b24jssdk по умолчанию **повторяет** запрос при сетевой ошибке, таймауте и ответе 5xx
  (`retryOnNetworkError`, до 3 попыток — код пакета 2.2.0). Приложение пишет в портал то, что
  повторять нельзя (`event.bind`, дальше — регистрация провайдеров), поэтому повторы выключены один
  раз при создании фрейма (`app/config/b24.ts → sdkRestrictionParams`). Невыполненные порталом
  запросы (лимиты, 429) SDK по-прежнему повторяет.
